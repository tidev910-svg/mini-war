02

Tải dự án về lần đầu

git clone

Mở terminal tại thư mục muốn chứa dự án (ví dụ D:\Game), rồi chạy:

git clone https://github.com/tidev910-svg/mini-war.git
cd mini-war

Lệnh git clone tạo thư mục mini-war chứa toàn bộ mã nguồn và lịch sử thay đổi.

Kho để chế độ riêng tư (private)?Bạn cần được chủ kho mời làm cộng tác viên. Khi Git hỏi đăng nhập, cửa sổ đăng nhập GitHub sẽ hiện ra. Nếu đã cài GitHub CLI, có thể chạy gh auth login trước.
03

Cài thư viện và chạy game

pnpm

Trong thư mục dự án:

pnpm install
pnpm dev

Rồi mở trình duyệt vào http://localhost:5173/.

  • pnpm install chỉ cần chạy lần đầu, và chạy lại mỗi khi package.json hoặc pnpm-lock.yaml thay đổi sau một lần pull.
  • Muốn dừng server: bấm Ctrl+C trong terminal.
  • Cách nhanh trên Windows: bấm đúp file start-game.bat. Vẫn phải chạy pnpm install một lần trước đó.

Các lệnh khác

LệnhTác dụng

Chơi với bạn bè trong cùng mạng Wi-Fi/LANMáy kia mở địa chỉ Network mà terminal in ra sau khi chạy pnpm dev (dạng http://192.168.x.x:5173/). Cả hai máy cần có Internet để kết nối P2P.
04

Cập nhật bản mới nhất

Mỗi lần bắt đầu làm việc

Lấy thay đổi mới nhất từ GitHub về:

git pull
pnpm install

pnpm install ở đây phòng trường hợp có thư viện mới. Nếu không có gì thay đổi, lệnh chạy rất nhanh.

Pull báo lỗi vì bạn đang có thay đổi chưa lưu?Tạm cất thay đổi, pull, rồi lấy lại:
git stash
git pull
git stash pop
05

Lưu và gửi thay đổi của bạn

commit & push
status→add→commit→pull→push
git status                      # xem file nào đã thay đổi
git add -A                      # chọn tất cả thay đổi để lưu
git commit -m "Mô tả ngắn thay đổi"
git pull                        # lấy bản mới nhất trước khi gửi, tránh xung đột
git push                        # gửi lên GitHub

Lệnh xem thông tin hay dùng

LệnhTác dụng
git statusTrạng thái hiện tại: file nào đã sửa, file nào mới
git log --oneline -1010 commit gần nhất
git diffXem chi tiết các dòng đã sửa nhưng chưa commit
git restore <file>Bỏ thay đổi chưa commit của một file. Không lấy lại được.

Làm việc trên nhánh riêng

Nên dùng khi làm tính năng lớn, hoặc khi nhiều người cùng làm.

git switch -c ten-tinh-nang     # tạo nhánh mới và chuyển sang
# ... sửa code, commit ...
git push -u origin ten-tinh-nang

Sau đó vào trang GitHub của kho để tạo Pull Request gộp vào nhánh main.
